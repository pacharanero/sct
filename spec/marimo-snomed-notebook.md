# SNOMED-aware notebook workbench

Status: Relocated to the public [`sct-marimo`](https://github.com/pacharanero/sct-marimo) project on 2026-10-16.

The product hypothesis, architecture, trust boundaries, safety constraints, validation slices, and roadmap now live in [`sct-marimo/spec/product.md`](https://github.com/pacharanero/sct-marimo/blob/main/spec/product.md). This repository remains authoritative for RF2 ingestion, canonical NDJSON, derived databases, ECL semantics, hierarchy queries, provenance, and the typed Rust/Python SDK used by that workbench.

The original exploratory design remains available at commit [`6384c9a`](https://github.com/pacharanero/sct/blob/6384c9a2c0c39f73a66e133b2641d56f9ea92be3/spec/marimo-snomed-notebook.md). The broader marimo/Jupyter interoperability discussion in [issue #42](https://github.com/pacharanero/sct/issues/42) remains open and is not made an `sct` roadmap commitment by this relocation.
